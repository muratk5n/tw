Paper: "When Modernization Breaks Working Code: A Single-File Study of LLMs on Legacy PHP.. Pasting a legacy file into an LLM and asking it to 'modernize this' is an easy shortcut. In this paper, we study this single-file setting with five LLMs, each asked to modernize 100 WordPress 4.0 PHP files to PHP 8.3 while preserving behavior, with no project context or execution feedback. We evaluate every output with 630 hidden behavioral checks and 511 Rector-detected modernization findings. We compare against two baselines: the unchanged originals and the rule-based tool Rector.
