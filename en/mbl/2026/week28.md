narrative-related features out of LLM texts (yes, they used LLMs to
help detect LLMs). They prompted these secondary LLMs with directions
like "count the number of active subplots (integer) in this story",
"does the narrator state the moral explicitly in this story (1/0)?".

for each text. They essentially created structured representations
from texts, a "fingerprint", that subsequent tools can now analyze
downstream. After a few more transformations they could even cluster
these feature vectors. They found similarities, fingerprints from LLMs

There are probabilistic programming options. First trick: Running
plain old regression on normalized time series X,Y is the same thing
as computing correlation between X,Y. Another trick, we use "segmented
regression", find pieces of linear fit within blocks, once found, we
run correlation (w/ significance calc) between endpoints. Lines are
connected via a sigmoid, we run Metropolis sampling over the
"posterior".
